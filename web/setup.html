打开 PocketDesk

如果之前是直接信任进来的（），也可以继续这样用； 偶尔又提示不安全时，再点一次就行。想彻底不提示，可以按下面的步骤安装证书。

第一次连接这台电脑，需要先信任它的证书，有两种方式（每部手机对每台电脑只做一次）：

方式一：直接打开（最省事）
点下面的按钮，Safari 提示“此连接不是私密连接”时，点“显示详细信息 → 访问此网站”。 点下面的按钮，Chrome 提示“您的连接不是私密连接”时，点“高级 → 继续前往 …（不安全）”。
直接打开 PocketDesk

方式二：安装证书（更稳定）：以后不会再提示，切换电脑时也一定能连上。

  1. 下载这台电脑的证书：
    下载证书
    弹出“此网站正尝试下载一个配置描述文件”时，点“允许”。
  2. 打开“设置”，点顶部的“已下载描述文件”，然后点“安装”（需要输入锁屏密码）。
  3. 打开“设置 → 通用 → 关于本机 → 证书信任设置”，打开 {{CA_NAME}} 的开关。
  4. 回到 Safari，打开 PocketDesk：
    打开 PocketDesk
  1. 下载这台电脑的证书，会存到“下载”文件夹：
    下载证书
  2. 打开“设置”，在顶部搜索框搜 CA 证书，点“安装 CA 证书”（或“从存储设备安装”）， 提示有风险时点“仍然安装”，然后在“下载”里选 {{CA_NAME}}.crt。
    搜不到时可以找：设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书。各品牌位置略有不同。
  3. 回到 Chrome，打开 PocketDesk：
    打开 PocketDesk
    建议用 Chrome 或 Edge。Firefox 默认不认手机里装的证书，只能用方式一。
